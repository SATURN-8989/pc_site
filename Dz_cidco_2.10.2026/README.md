# Лабораторная работа по компьютерным сетям
## Тема Подготовка топологии к маршрутизации RIP и OSPF

Подготовлена схема корпоративной сети в Cisco Packet Tracer согласно требованиям двух лекционных презентаций

### Описание структуры сети
* **Маршрутизаторы** Использованы три роутера Cisco 1941 объединенные в кольцевую топологию OSPF для обеспечения отказоустойчивости каналов связи
* **Аппаратные модули** В каждый роутер интегрирована плата расширения HWIC-2T со скоростными интерфейсами Serial для организации магистральных линий
* **Локальные сети** К каждому роутеру через коммутаторы Cisco 2960 подключены пользовательские подсети


Интерфейсы устройств намеренно оставлены в выключенном состоянии Окончательное включение портов и настройка протоколов динамической маршрутизации RIP и OSPF будут выполнены непосредственно на лабораторном занятии
